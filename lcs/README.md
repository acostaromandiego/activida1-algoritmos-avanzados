# LCS: recursiva, Hirschberg y programación dinámica

Requisitos: Python 3.8+ (matplotlib opcional, solo para la gráfica).

Ejecutar todo (pruebas + experimentos) con un único comando:

    make

- `lcs.py`: las tres versiones.
- `tests.py`: juego de pruebas (206 casos).
- `experimentos.py`: genera `resultados/mediciones.csv` y `resultados/grafica.png`.
- `make demo`: ejemplo del Tema 3 (cadenas ACCGG... / GTCGT...).
